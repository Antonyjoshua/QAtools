# Portfolio 3 — SRH-Style Portfolio

HTML / CSS / JavaScript portfolio with Sunrisers Hyderabad-inspired orange fire design, project carousel, and animated counters.

## Run

Open `index.html` directly in a browser, or use the dev server:

```bash
npm install
npm run dev
```

Runs on http://localhost:5001

## Tech

Vanilla HTML · CSS · JavaScript · Google Fonts (Bebas Neue + Inter)
