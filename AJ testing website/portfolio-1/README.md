# Portfolio 1 — Original 3D Portfolio

HTML / CSS / JavaScript portfolio with Three.js 3D background, chatbot, and theme switching.

## Run

Open `index.html` directly in a browser, or use the dev server:

```bash
npm install
npm run dev
```

Runs on http://localhost:5000

## Pages

- `index.html` — main portfolio
- `contact-form.html` — contact form page
- `bug-robot.html` — bug robot page
- `bug-report.html` — bug report page
- `catch-the-bug.html` — catch the bug game
- `spot-the-bug.html` — spot the bug game

## Tech

Vanilla HTML · CSS · JavaScript · Three.js (local) · Google Fonts
