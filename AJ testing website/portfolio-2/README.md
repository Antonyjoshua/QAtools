# Portfolio 2 — Next.js 3D Portfolio

Next.js 14 portfolio with React Three Fiber 3D scene, Framer Motion animations, and theme switching.

## Run

```bash
npm install
npm run dev
```

Runs on http://localhost:3000

## Build

```bash
npm run build
```

Generates static export in the `out/` folder.

## Tech

Next.js 14 · React 18 · TypeScript · Three.js · React Three Fiber · Framer Motion · Tailwind CSS
